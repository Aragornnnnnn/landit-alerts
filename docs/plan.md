# 공식 API 전환 설계

2026-08-11 확정. 이 문서가 앞으로의 작업 기준이다.

## 결정

- 데이터 소스는 **공식 인증 API만 쓴다.** 공개 엔드포인트(RSS·lookup·페이지 파싱)는 키 등록과 함께 삭제한다.
  - 배경: 공개 엔드포인트는 CDN 캐시라 배포 직후 값이 흔들려 가짜 알림을 만들었다 ([실사례](alert-flow.md)).
- 채널은 두 개로 확정한다.
  - `#⭐-앱-리뷰` — 리뷰만.
  - `#🚀-앱-소식` — 나머지 전부 (릴리즈·심사·빌드·롤아웃·다운로드 요약).
- 평점 변동 알림은 하지 않는다. 평균 평점은 공식 API가 없는 유일한 데이터고, 별점만 남긴 평가는 대응할 것이 없다.

## 최종 알림 목록

| 알림                             | 채널          | 데이터 소스 (전부 공식)          |
| -------------------------------- | ------------- | -------------------------------- |
| 새 리뷰 (iOS)                    | `#⭐-앱-리뷰` | ASC API customerReviews          |
| 새 리뷰 (Android, 기기·OS 포함)  | `#⭐-앱-리뷰` | Play Developer API reviews       |
| 새 버전 공개 (iOS)               | `#🚀-앱-소식` | ASC API appStoreVersions         |
| 새 버전 공개 (Android)           | `#🚀-앱-소식` | Play Developer API 프로덕션 트랙 |
| 심사 통과·거절 (iOS만 가능)      | `#🚀-앱-소식` | ASC API                          |
| 빌드 처리 완료·실패 (iOS만 가능) | `#🚀-앱-소식` | ASC API                          |
| 롤아웃 진행률 (양쪽)             | `#🚀-앱-소식` | ASC·Play API                     |
| 다운로드 주간 요약 (양쪽)        | `#🚀-앱-소식` | 애플 Sales 리포트 · 구글 통계    |

리뷰 답글은 알림에 붙는 기능으로 별도 구현한다.
버튼 → 모달 작성 → 스토어 API 전송, 성공하면 버튼이 ✏️ 수정으로 바뀐다(기존 내용 프리필, 양쪽 스토어 다 수정 지원).
버튼 클릭을 받을 수신 서버(Cloudflare Workers)가 필요해서 마지막 단계다.

## 필요한 키와 Secrets

| Secret                                             | 내용                | 사용처       |
| -------------------------------------------------- | ------------------- | ------------ |
| `DISCORD_WEBHOOK_REVIEW`                           | 리뷰 채널 웹훅      | 등록됨       |
| `DISCORD_WEBHOOK_UPDATE`                           | 앱-소식 채널 웹훅   | 등록됨       |
| `ASC_ISSUER_ID` / `ASC_KEY_ID` / `ASC_PRIVATE_KEY` | ASC API 키 (.p8)    | iOS 전체     |
| `PLAY_SERVICE_ACCOUNT_JSON`                        | 서비스 계정 키 JSON | Android 전체 |

키 발급 요약.

- **ASC** — App Store Connect → 사용자 및 액세스 → 통합 → 팀 키 생성(App Manager). .p8은 생성 직후 한 번만 다운로드된다.
- **Play** — Cloud Console에서 서비스 계정 생성 + JSON 키 발급 → Play Console → 사용자 및 권한에서 그 계정을 초대(앱 정보 보기 + 리뷰에 답장).

## 작업 순서

| 순서 | 작업                                                                | 조건               | 상태    |
| ---- | ------------------------------------------------------------------- | ------------------ | ------- |
| 1    | iOS를 ASC API로 전환 (리뷰·버전·심사), RSS·lookup 삭제              | ASC 키             | 키 대기 |
| 2    | Android를 Play API로 전환 (리뷰 활성화·트랙 버전), 페이지 파싱 삭제 | Play 키            | 키 대기 |
| 3    | 빌드 처리 알림                                                      | 1 완료             | 대기    |
| 4    | 롤아웃 진행률 알림                                                  | 1·2 완료           | 대기    |
| 5    | 다운로드 주간 요약                                                  | 1·2 완료           | 대기    |
| 6    | 리뷰 답글 (버튼·모달·수정)                                          | 1·2 완료 + Workers | 대기    |

키 두 개가 시차를 두고 와도 온 쪽부터 진행한다.
전환 전까지는 현행(공개 엔드포인트 + 흔들림 방어)으로 운행한다.
